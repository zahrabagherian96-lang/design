# قالب وردپرس روزا | ROZA Beauty Lounge

قالب فارسی و راست‌چین سالن زیبایی بانوان، با رزرو آنلاین نوبت (تقویم شمسی)، حساب کاربری مشتری، گالری نمونه‌کار، معرفی متخصصان، انیمیشن‌های اسکرول و سئوی کامل. همه محتوا از پیشخوان قابل‌تغییر است و به هیچ افزونه‌ای نیاز ندارد.

- وردپرس ۶٫۳ به بالا، PHP ۷٫۴ به بالا
- آزمایش‌شده روی وردپرس ۶٫۶ (PHP ۸٫۳)

## نصب
1. پوشه `roza` را زیپ کنید (یا از فایل `roza-wordpress-theme.zip` استفاده کنید). سپس در «پیشخوان ← نمایش ← پوسته‌ها ← افزودن ← بارگذاری پوسته» آن را نصب و فعال کنید.
2. در «نمایش ← راه‌اندازی روزا» دکمه **راه‌اندازی** را بزنید. این کار برگه‌ها، صفحه اصلی و منو را می‌سازد و اگر بخواهید محتوای نمونه هم اضافه می‌کند.
3. «تنظیمات ← پیوندهای یکتا» را روی «نام نوشته» بگذارید. راه‌اندازی خودکار این کار را انجام می‌دهد، مگر اینکه از قبل ساختاری تنظیم شده باشد.
4. منطقه زمانی سایت باید «تهران» باشد. با فعال شدن قالب، اگر روی UTC بود خودکار تنظیم می‌شود.

## رزرو نوبت
- زمان‌های آزاد از روی ساعت کاری سالن، روزهای کاری هر متخصص و نوبت‌های ثبت‌شده محاسبه می‌شود.
- سرور هنگام ثبت دوباره بررسی می‌کند: تداخل، ساعت کاری، تعطیلی، بازه رزرو و زمان گذشته.
- رزرو هم‌زمان یک زمان ممکن نیست.
- گزینه «اولین متخصص آزاد» اولین متخصص آزاد را خودکار انتخاب می‌کند.
- هر نوبت در منوی «نوبت‌ها» ثبت می‌شود. ایمیل اطلاع‌رسانی برای مدیر قابل خاموش کردن است.
- **محافظت:** کد امنیتی (nonce)، تله ربات، و محدودیت ۱۵ رزرو در ساعت برای هر بازدیدکننده.
- **صفحه نتیجه:** فقط با کد و توکن خصوصی همان رزرو باز می‌شود و در نتایج جست‌وجو نمایش داده نمی‌شود (noindex).

## حساب کاربری مشتری و پیامک
- مشتری با موبایل و کد یک‌بارمصرف وارد می‌شود. کد ۵ دقیقه اعتبار دارد و حداکثر ۵ تلاش مجاز است.
- نشست مشتری در کوکی امضاشده ۳۰ روزه ذخیره می‌شود.
- مشتری نوبت‌های پیش رو و گذشته را می‌بیند و می‌تواند زمان را تغییر دهد یا نوبت را لغو کند. قانون بیعانه در پنجره لغو نمایش داده می‌شود.
- نام و «نکات مهم برای سالن» در رزروهای بعدی خودکار پر می‌شود.

**حالت پیش‌فرض نمایشی است:** کد ورود روی صفحه نشان داده می‌شود. برای سایت واقعی، در «سفارشی‌سازی ← رزرو نوبت و قوانین»، گزینه «ارسال کد ورود مشتری» را روی **درگاه پیامک** بگذارید. سپس این کد را در افزونه‌ای کوچک یا فایل functions.php پوسته فرزند اضافه کنید و وب‌سرویس پیامک خود (کاوه‌نگار، ملی‌پیامک، فراز اس‌ام‌اس و…) را صدا بزنید:

```php
add_filter( 'roza_send_otp', function ( $sent, $mobile, $code ) {
	$res = wp_remote_post( 'https://api.example-sms.ir/send', array(
		'body' => array( 'to' => $mobile, 'text' => 'کد ورود روزا: ' . $code ),
	) );
	return ! is_wp_error( $res ) && 200 === wp_remote_retrieve_response_code( $res );
}, 10, 3 );
```

قلاب‌های دیگر برای اتصال پیامک تأیید، تقویم یا CRM:
- `roza_booking_created` با شناسه نوبت
- `roza_booking_cancelled` با شناسه نوبت
- `roza_booking_status_changed` با شناسه نوبت و وضعیت جدید

## سئو
- HTML همه صفحات سمت سرور ساخته می‌شود. هر صفحه یک H1 و مسیر صفحه (breadcrumb) دارد.
- **برچسب‌ها:** عنوان، توضیحات متا، canonical، Open Graph و کارت توییتر. هر برگه، خدمت و متخصص باکس «سئو» دارد: عنوان، توضیحات و noindex.
- **داده ساختاریافته (JSON-LD):**
  - `BeautySalon` با آدرس، تلفن، ساعات کاری، مختصات و فهرست خدمات
  - `Service` با قیمت به ریال (تومان واحد استاندارد ISO نیست)
  - `Person` برای متخصصان
  - `FAQPage`، `BreadcrumbList` و `WebSite`
- نقشه سایت داخلی وردپرس (`/wp-sitemap.xml`) شامل خدمات و متخصصان است. نوبت‌ها، مشتریان و کاربران در آن نیستند.
- حساب کاربری، صفحه نتیجه رزرو و جست‌وجو noindex هستند.
- **سرعت:** فونت وزیرمتن به‌صورت فایل woff2 محلی با preload، تصویر هیرو با preload و fetchpriority، تصاویر دیگر lazy با srcset، و اسکریپت‌ها با defer.
- اگر Yoast، Rank Math، AIOSEO یا SEOPress فعال باشد، قالب برچسب‌های متا را به آن می‌سپارد و فقط اسکیمای کسب‌وکار، خدمات و پرسش‌ها را اضافه می‌کند.
- **ستاره امتیاز:** قالب امتیاز کلی (aggregateRating) نمی‌سازد، چون گوگل امتیاز «خوداظهاری» کسب‌وکار را نمی‌پذیرد.

## حرکت و دسترس‌پذیری
- **حرکت:** اسکرول نرم (Lenis)، GSAP ScrollTrigger، خدمات افقیِ پین‌شده، ستون‌های پارالاکس، کرسر سفارشی و دکمه‌های مغناطیسی. همه از «سفارشی‌سازی ← برند و عمومی» خاموش می‌شوند و با تنظیم «کاهش حرکت» سیستم هم غیرفعال می‌شوند.
- **دسترس‌پذیری:** فوکوس کیبورد، لایت‌باکس و منوی قابل‌کنترل با کیبورد (فلش‌ها با منطق راست‌به‌چپ)، برچسب‌های فرم و پیام خطا کنار فیلد.

## تصاویر نمونه
تصاویر محتوای نمونه عکس‌های Pexels هستند (مجوز رایگان Pexels) و فقط برای پیش‌نمایش‌اند. پیش از انتشار، عکس‌های واقعی سالن، نمونه‌کارها و کارکنان را جایگزین کنید. در پیش‌فرض، تصاویر از Pexels نمایش داده می‌شوند. با تیک «دانلود تصاویر نمونه» در صفحه راه‌اندازی، تصاویر در کتابخانه رسانه ذخیره می‌شوند. فهرست منابع در `roza/README.md` پروژه HTML آمده است.
