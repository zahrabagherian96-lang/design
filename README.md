# در بیرجند کجا؟

راهنمای مشاغل و نظرات مردم بیرجند؛ الهام‌گرفته از Trustpilot، باتابه و میدانه. فارسی، راست‌چین، تم سبز، فونت وزیرمتن و پر از موشن.

## صفحات
| صفحه | فایل |
|---|---|
| خانه | `index.html` |
| کاوش و جستجو با فیلتر (دسته، محله، امتیاز، قیمت، باز/تأییدشده، مرتب‌سازی، نمای شبکه/فهرست) | `search.html` (مثلاً `search.html#cat-food~hood-moallem`) |
| دسته‌بندی‌ها | `categories.html` |
| محله‌ها با نقشه تعاملی | `hoods.html` |
| صفحه هر کسب‌وکار با گالری و لایت‌باکس | `place.html#p1` تا `place.html#p28` |
| مجله و مطالب | `blog.html`، `article.html#a1` … |
| ویژه کسب‌وکارها (تعرفه، ثبت چندمرحله‌ای، احراز مالکیت، پرسش‌ها) | `business.html` |
| داشبورد نمایشی کسب‌وکار | `dashboard.html` |
| ورود با موبایل و کد تأیید (کد نمایشی: 12345) | `login.html` |
| پروفایل (علاقه‌مندی‌ها، نظرات من، تنظیمات) | `profile.html` |
| درباره ما، تماس، قوانین نظردهی، حریم خصوصی، فرصت‌های شغلی، ۴۰۴ | `about.html` … `404.html` |

## ساختار
- `assets/css/style.css` و `pages.css`: توکن‌ها و کامپوننت‌ها
- `assets/js/data.js`: داده‌های نمونه (۲۸ مکان، مقاله‌ها، شغل‌ها)
- `assets/js/core.js`: هدر، فوتر، مودال ثبت نظر، علاقه‌مندی‌ها و موشن مشترک
- `assets/js/pages.js`: منطق هر صفحه
- `assets/fonts/`: فونت وزیرمتن (مجوز OFL)
- `assets/img/photos/`: عکس‌ها

## نکته‌ها
- نام کسب‌وکارها، تلفن‌ها، قیمت‌ها و نظرات **نمونه** هستند. جاذبه‌ها (باغ اکبریه، ارگ کلاه‌فرنگی، قلعه بیرجند، بند دره) واقعی‌اند.
- عکس‌ها **نمایشی** هستند و از قالب‌های متن‌باز GitHub (StartBootstrap، Creative Tim، ThemeWagon، Themefisher، Material Design Lite) برداشته شده‌اند؛ تصویر خود مکان‌های بیرجند نیستند. پیش از انتشار عمومی، عکس‌های واقعی جایگزین شوند و مجوز هر عکس بررسی شود.
- سایت بک‌اند ندارد. ورود، علاقه‌مندی‌ها و نظرات فقط در مرورگر همان کاربر ذخیره می‌شوند.

## اجرا
```bash
python3 -m http.server 8000
```
سپس `http://localhost:8000` را باز کنید.
