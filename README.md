# در بیرجند کجا؟

راهنمای مشاغل و نظرات مردم بیرجند — الهام‌گرفته از Trustpilot، باتابه و میدانه. فارسی، راست‌چین، تم سبز و پر از موشن.

## صفحات
- `index.html` — صفحه اصلی: جستجو با پیشنهاد زنده، دسته‌بندی‌ها، فیلتر برترین‌ها، محله‌ها (اسکرول افقی)، آمار، نظرات تازه، برترین‌های ماه، بخش کسب‌وکارها، خبرنامه
- `place.html?id=N` — صفحه هر کسب‌وکار: گالری، امتیاز و توزیع ستاره‌ها، نظرات، اطلاعات تماس، مکان‌های مشابه

## ساختار
- `assets/img/logo-mark.svg` و `logo-full.svg` — لوگو (پین نقشه + گنبد کلاه‌فرنگی بیرجند)
- `assets/css/style.css` — توکن‌های طراحی، کامپوننت‌ها، ریسپانسیو و `prefers-reduced-motion`
- `assets/js/data.js` — داده‌های نمونه (نام کسب‌وکارها فرضی است)
- `assets/js/main.js` — تعاملات و انیمیشن‌ها با GSAP (ScrollTrigger و Flip)

## اجرا
فایل‌ها کاملاً استاتیک‌اند؛ `index.html` را در مرورگر باز کنید یا:

```bash
python3 -m http.server 8000
```
