# در بیرجند کجا؟

راهنمای مردمی کسب‌وکارهای بیرجند؛ فارسی، راست‌چین، رنگ سبز یشمی روشن و نماد درخت کاج.

## اجرا
فایل zip را از حالت فشرده خارج کنید و روی `index.html` دو بار کلیک کنید. سایت بدون اینترنت و بدون نصب برنامه کار می‌کند و همه صفحه‌ها به هم لینک‌اند.

## صفحات
| صفحه | فایل |
|---|---|
| خانه: جستجو، آمار، دسته‌ها، نقشه بیرجند با کارت روی نشانگر، محله‌ها، نظرات، مجله | `index.html` |
| فهرست نتایج هر دسته با فیلتر و نقشه | `search.html` (مثلاً `search.html#cat-food`) |
| دسته‌بندی‌ها با زیرشاخه‌ها | `categories.html` |
| نقشه کامل و محله‌ها | `hoods.html` |
| صفحه هر کسب‌وکار با گالری، نقشه و نظرات | `place.html#p1` … |
| مجله و مطالب | `blog.html`، `article.html#a1` … |
| ثبت کسب‌وکار و احراز مالکیت (کارت ملی، جواز کسب، موبایل) | `business.html` |
| پنل مدیریت | `admin.html` (رمز نمایشی: `admin`) |
| ورود با موبایل، پروفایل | `login.html`، `profile.html` (کد نمایشی: `12345`) |
| درباره ما، تماس، قوانین، حریم خصوصی، فرصت‌های شغلی، ۴۰۴ | سایر فایل‌ها |

## روند تأیید
- **نظر دادن:** فقط با شماره موبایل تأییدشده. نظر پس از ثبت «در انتظار تأیید» است و پس از تأیید مدیر منتشر می‌شود.
- **ثبت کسب‌وکار:** اطلاعات کسب‌وکار، کد ملی، تصویر کارت ملی، شماره و تصویر جواز کسب، و تأیید موبایل. پس از تأیید مدیر در سایت نمایش داده می‌شود.
- **پنل مدیریت:** تأیید یا رد کسب‌وکارها و نظرات، کاربران جدید، پربازدیدترین صفحات، افزودن، حذف و تغییر نام دسته‌بندی‌ها.

## محدودیت‌های نسخه نمایشی
- سایت بک‌اند ندارد. حساب‌ها، نظرات، درخواست‌ها و تصمیم‌های مدیر فقط در مرورگر همان دستگاه ذخیره می‌شوند. رمز مدیر و کد پیامک نمایشی‌اند و برای سایت واقعی باید سمت سرور پیاده شوند.
- نقشه بیرجند نمایشی و تقریبی است؛ برای نسخه واقعی می‌توان نقشه نشان یا OpenStreetMap را جایگزین کرد.
- نام کسب‌وکارها، تلفن‌ها، قیمت‌ها و نظرات نمونه‌اند. عکس‌ها نمایشی‌اند و از قالب‌های متن‌باز GitHub برداشته شده‌اند؛ پیش از انتشار عمومی عکس‌های واقعی جایگزین و مجوزها بررسی شود.

## ساختار
- `assets/css/fonts.css`: فونت‌های وزیرمتن و نوتو نسخ (مجوز OFL) به‌صورت جاسازی‌شده
- `assets/css/style.css`، `pages.css`: ظاهر سایت
- `assets/js/data.js`: داده‌ها · `core.js`: هدر، فوتر، نقشه، ثبت نظر · `pages.js`: منطق هر صفحه
- `assets/vendor/gsap.min.js`: کتابخانه انیمیشن
