## شکل و عمق
`--r-sm 4px`، `--r-md 8px` (دکمه/فرم)، `--r-lg 16px`. تصاویر تقریباً تیز (۴px) برای حس معماری. سایه فقط برای عناصر شناور (کارت نشان هیرو، پنل پیش‌نمایش، hover دکمه).

## کنترل‌ها و حالت‌ها
دکمه: پیش‌فرض، hover (رنگ + سایه + حرکت فلش ۴px)، focus-visible (حلقهٔ ۳px)، active (فشردن ۱px)، disabled، loading (اسپینر). فرم: پیش‌فرض، hover، focus، error (`aria-invalid` + پیام + آیکون)، success، disabled. آکاردئون: باز/بسته با آیکون + و −. اسلایدر: دکمه‌های قبلی/بعدی، نقطه‌ها (tablist)، توقف خودکار.

## موشن
| توکن | مقدار |
|---|---|
| `--ease` | cubic-bezier(.22, 1, .36, 1) |
| `--dur-fast / ui` | 180 / 260ms |
| `--dur-enter / slow` | 700 / 900ms |
| `--stagger` | 80ms |
| `--rv-dist` | 28px (کم: ۰، متعادل: ۲۸، کامل: ۴۴) |

شدت موشن با `html[data-motion="off|low|balanced|full"]` کنترل می‌شود (در وردپرس: Customizer). `prefers-reduced-motion` خودکار به `off` می‌رود. فقط `transform` / `opacity` / `clip-path` انیمیت می‌شوند.

| سطح | رفتار |
|---|---|
| خاموش | همه‌چیز بلافاصله نمایش داده می‌شود |
| کم | فقط fade کوتاه؛ بدون جابه‌جایی، پارالاکس و چرخش تزئینی |
| متعادل | reveal، hover، شمارنده، پارالاکس نیم‌قدرت (فقط دسکتاپ) |
| کامل | همهٔ موارد با جابه‌جایی و پارالاکس بیشتر |

## دسترس‌پذیری (پیاده‌شده)
یک H1؛ سلسله‌مراتب H2/H3؛ لینک «پرش به محتوا»؛ `focus-visible` همه‌جا؛ منوی موبایل: `role=dialog`، تله‌فوکوس، Esc، `inert` روی پس‌زمینه، بازگردانی فوکوس؛ آکاردئون با `aria-expanded/controls` و کلیدهای ↑ ↓ Home End؛ اسلایدر با `aria-roledescription`، فلش‌های کیبورد (جهت RTL)، swipe، توقف خودکار و ارتفاع ثابت؛ هدف‌های لمسی ≥۴۴px (به‌جز لینک‌های درون‌متنی).
